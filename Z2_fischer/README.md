# WEBTE1 - Zadanie č. 2: Obedové menu v okolí fakulty

* **Meno:** Daniel Fischer  
* **Krúžok:** B-API-MSUS  
* **Odkaz na školskom serveri:** [https://webte1.fei.stuba.sk/~xfischerd/ZZ_fischer]
* **Odkaz na GitHub repozitár:** [https://github.com/D4N0-1/webte1]

Webová aplikácia určená na asynchrónne načítanie, spracovanie a prehľadné zobrazenie denného menu reštaurácií v okolí FEI STU. Spracovanie prebieha výhradne na strane klienta (HTML, CSS, JavaScript).

## Použitie AI nástrojov
V súlade s podmienkami zadania uvádzam použitie AI nástrojov pri vývoji:
- **Google Gemini**: Použitý ako asistent na návrh štruktúry projektu, tvorbu DOMParser logiky, konzultáciu CSS layoutu a vysvetlenie princípov fungovania kódu pre obhajobu.

## Štruktúra adresára
- `index.html` - Hlavný HTML5 dokument
- `favicon.ico` - Favicon ikona stránky

- `script/app.js` - Hlavná JS logika aplikácie
- `fonts/` - Priečinok pre lokálne `.woff2` súbory fontu
- `docs/` - Priečinok pre screenshoty/textové výpisy z W3C validátorov
